**Runtime:** About 60 seconds\
**Platform shown:** Windows 11, Free Tier build\
**Voice:** Calm, plain, and unhurried. Read it like you're showing a friend what's on your screen.\

## Production Notes

- **Spoken word count:** About 104 words, which fits a calm pace inside 60 seconds.
- **Match the page.** Scene start times line up with the six timestamps on the See It Work page: 0:00, 0:08, 0:15, 0:27, 0:36, and 0:45. If the final cut shifts, update the page timestamps the same day.
- **Real capture only.** Record the current Free Tier build on a real Windows 11 machine. Don't recreate or mock up any screen. If anything is recreated, remove "Nothing is mocked up" from the page.
- **Trimming.** Cut loading time if needed, but keep the "trimmed for length" caption on the page so the video doesn't suggest faster speeds than users will see.
- **Blur everything personal.** Blur the ChatGPT email, password field, profile image, and any non-demo thread titles. Never show a session token or license key. If a license key appears anywhere in the capture, blur it.
- **Demo thread.** Use a non-sensitive "Pricing research" thread. The filenames must read exactly `2026-09-14-pricing-research.md` and `2026-09-14-pricing-research.json`, matching the page screenshot and evidence strip.
- **Final frame.** The Markdown and JSON files are both open beside the Library folder. Export this frame at 2x resolution for the page's poster image.
- **Captions.** Burn them in or ship a default-on WebVTT track. Use the same wording as the on-screen text above, and paste the final caption text into the page transcript.
- **Visual style.** Keep editing minimal. Use straight cuts or short crossfades only. Avoid zoom punches, fast cuts, motion graphics, and flying logos. Caption cards use Obsidian backgrounds, Paper text, and Steel Blue mono for file paths. The closing CTA is the only Archive Amber element.
- **Cursor.** Use a slightly enlarged cursor with a soft click highlight so viewers can follow each action.
- **Accuracy checks.** Before recording, confirm the app still ships as a portable unzip-and-run build. Also confirm the folder path, the filename pattern, the Free Tier provider list, and whether the limit reads "per provider" or "per download."
- **Re-record trigger.** Re-record the demo if ChatGPT's sign-in flow or the TotalRecalls interface changes in a visible way.
