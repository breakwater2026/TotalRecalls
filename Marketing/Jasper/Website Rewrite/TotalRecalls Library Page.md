### 2. What the Library Is

`WHAT IT IS`

## A folder, not a platform

The Library has no database to learn and no viewer you have to keep installed. When a download finishes, your chats are just files on your drive, sitting in folders you can see.

- **It lives on your drive.** The path is `C:\TotalRecalls\Library\`. Nothing sits between you and the files.
- **It grows as you download.** Each new download adds files to the right provider subfolder.
- **It works without the app.** Close TotalRecalls, or uninstall it. The folder and every file in it stay put on your drive.

`C:\TotalRecalls\Library\perplexity\2026-07-21-market-scan.md` · `.MD` · `.JSON`

### 3. How It's Organized

*Anchor: `id="structure"`*

`THE STRUCTURE`

## Filed by provider, named by date

Every provider gets its own subfolder. Inside, each conversation is saved as a Markdown file for reading and a JSON file for data, both named with the date and the chat's title.

```
C:\TotalRecalls\Library\
├── chatgpt\
│   ├── 2026-08-01-pricing-research.md
│   ├── 2026-08-01-pricing-research.json
│   └── …
├── claude\
│   ├── 2026-07-28-refactor-plan.md
│   ├── 2026-07-28-refactor-plan.json
│   └── …
├── perplexity\
├── gemini\        converted from Google Takeout
├── grok\
├── deepseek\
├── mistral\
└── qwen\
```

**Diagram caption:** Eight subfolders. Dated file names. Sorted by date the moment you open a folder.

#### Two files, two jobs

**The `.md` file is for reading.**\
Markdown is plain text with light formatting. Headings, lists, and code blocks read cleanly in Notepad and look even better in any Markdown viewer.

**The `.json` file is for tools.**\
JSON holds the same conversation as structured data: who said what, and when. Use it if you want to script, sort, or import your chats into other software.

#### Inside a saved chat

```
# Pricing research
downloaded 2026-08-01 · provider: chatgpt · 14 messages

You: Compare one-time pricing for download tools.

Assistant: Here is a table of the options I found, with links and caveats…
```

Each file starts with a title and a short header showing the download date, the provider, and the message count. The conversation follows in order.

### 4. Why a Folder Works Better

`FOLDER VS SIDEBAR`

## Things you can do with files that a chat sidebar won't let you do

A chat sidebar is built for your next message. A folder is built for everything you've already said. That difference shows up in everyday tasks.

- **Look across tools in one place.** Research from Perplexity and a draft from Claude sit one folder apart, not in two separate browser tabs.
- **Sort your own way.** Sort by date, rename a file, or drag your key threads into a project folder. It's your filing system.
- **Quote without retyping.** Open a file, select the passage you need, and paste it into your document or email.
- **Keep an exact copy.** A saved file shows the conversation as it was on the day you downloaded it.

### 6. FAQ

`FAQ`

## Questions about the Library

**Do I need TotalRecalls installed to read my files?**\
No. The files are plain Markdown and JSON, so any text editor opens them. You only need the app to download new chats.

**Do I need Pro to open my Library?**\
No. Opening, searching, and copying your files works the same on the Free Tier and Pro. Pro adds all eight providers and removes the download cap.

**Why are Gemini chats handled differently?**\
Gemini history comes through Google Takeout. You request your Takeout archive, point TotalRecalls to it, and it converts your chats into Markdown and JSON files in the `gemini\` subfolder.

**Can I keep my Library in a synced cloud folder?**\
That's your call. TotalRecalls never uploads your chats. If you copy the Library to a cloud drive you manage, that copy follows that service's rules.

**Does the Library work offline?**\
Yes. Reading and searching saved files works offline. Downloading new chats needs an internet connection.
