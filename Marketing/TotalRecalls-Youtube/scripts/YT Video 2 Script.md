### Production Notes for All Three Hooks

- **Keep the rest of the video unchanged.** Each hook fills only the opening \~5-second window, so Scene 2 onward stays as written. Read your chosen hook's last line aloud, then the first line of Scene 2, and make sure the handoff sounds natural.

- **Adjust the Scene 6 callback.** Swap the callback line so it echoes the hook you choose:

  - **Option 1:** "Now you own the place." (taps the "OWNED" page)
  - **Option 2:** "Lunch cancelled." (a keyword typed into Windows Search pulls up the old chat instantly)
  - **Option 3:** "Sticky notes: retired." (peels the last note off the monitor)

- **Hold the pauses.** The humor lives in the timing. Let each beat run slightly longer than feels comfortable.

- **No real provider screens or logos.** Any chat window, sidebar, or prop in the hook should be blank and generic. Only TotalRecalls, Windows folders, Notepad, and Windows Search should ever appear sharp on screen.

- **No music for the first 2 seconds.** Let the VO and SFX carry the opening.

- **Keep props illustrative.** The "rental agreement" and sticky notes are comedic props. Don't imply that any specific provider will delete or restrict your chats.

- **Keep claims accurate.** If a hook or callback mentions saving chats, stick to what the product does. TotalRecalls saves chats to your own Windows PC as Markdown and JSON files.

### Split-Testing Guidance

- **Test one variable at a time.** Change only the hook. Keep the title, thumbnail, and every later scene identical.
- **Use Shorts cutdowns for quick reads.** Publish a short vertical cut of each hook version about a week apart. Compare how many viewers keep watching past the first 3 seconds versus swiping away.
- **Check long-form retention at 30 seconds.** For the full video, compare the audience retention curve at 0:30 across versions. A strong hook flattens the early drop-off.
- **Give each version enough time.** Run each test for at least 7 days before judging, so early spikes don't skew the result.
- **Compare against Video 1's winner.** If a hook style won in Video 1, note whether the same style wins again here. Patterns across videos are more reliable than a single result.
- **Carry the winner forward.** Once a hook wins, reuse its approach as the starting point for hooks in the rest of the series.
