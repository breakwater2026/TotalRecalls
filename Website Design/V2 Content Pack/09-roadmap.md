## Roadmap

### Available today

- Windows app (v1.3.0)
- Export from ChatGPT, Claude, Perplexity, Gemini (Takeout), Grok
- Local Markdown + JSON archive
- Private folder structure
- No cloud storage
- No subscription

### Coming soon

- Code-signed Windows builds
- Faster exports
- Better metadata + folder naming
- Gemini Takeout auto-merge
- Improved UI clarity

### Planned upgrades (optional)

- Semantic search across your archive
- Obsidian + Notion sync
- Multi-assistant timeline
- Multi-device memory
- RAG containers
- Personal memory engine
- Optional cloud sync (opt-in)

### Principles

- Your chats stay on your disk
- No forced subscription
- No cloud lock-in
- No hidden fees
- You own your archive
