# 21 — Competitive Positioning Brief (investor/partner-ready)

**Source:** Thread "Competitive Positioning Brief" (L2790–2879). Curated final copy. Lives in `marketing/`.

**Category:** AI conversation export + personal knowledge durability · Utility software (local-first)

**Problem:**
AI assistants are becoming the primary place where people think, plan, research, and write — but none of them give users real ownership of their conversations.

Official exports are: inconsistent · incomplete · cloud-dependent · unreadable · siloed · fragile · inconvenient.

Users need a durable, local, multi-assistant archive.

**Solution:**
TotalRecalls is a small Windows utility that exports ChatGPT, Claude, Perplexity, Gemini, and Grok conversations into a private folder on the user's PC — readable Markdown + JSON they keep forever.

**Differentiators:**
1. **Multi-assistant** — No official export covers multiple assistants.
2. **Local-first** — No cloud locker. No telemetry. No account.
3. **Markdown + JSON** — Readable, portable, durable.
4. **Clean folder structure** — Predictable, searchable, easy to back up.
5. **One-time purchase** — Utility pricing, not SaaS.
6. **Built for usability** — Official exports are built for compliance. TotalRecalls is built for real workflows.

**Market Position:**
TotalRecalls sits between: AI assistants (ChatGPT, Claude, Perplexity, Gemini, Grok) · personal knowledge tools (Obsidian, Notion, Logseq) · RAG/LLM memory systems (future roadmap).
It is the bridge between AI conversation and durable personal knowledge.

**Pricing:** Launch price: ~~$49~~ $24 one-time. No subscription. No monthly "AI archive" fee.

**Roadmap:** Code-signed builds · Faster exports · Better metadata · Semantic search · Obsidian/Notion sync · Multi-assistant timeline · Multi-device memory · RAG containers · Optional cloud sync (opt-in)

**Strategic Vision:** TotalRecalls becomes the personal memory layer for AI conversations — durable, local, and independent of any single assistant.
