TotalRecalls 1.0.0 — Free Tier
==============================

Thank you for downloading TotalRecalls.

WHAT THIS IS
------------
This is the FREE TIER of TotalRecalls — a full-featured Windows app that
downloads your AI chat history to local Markdown + JSON files you own.
No installation, no account, no telemetry. Just run TotalRecalls.exe.

FREE TIER INCLUDES
------------------
- All app features: Markdown + JSON downloads, provider-specific
  metadata, web-search result capture, per-conversation and bulk downloads
- 3 providers: Perplexity, ChatGPT, Claude
- Up to 5 conversations per download

QUICK START
-----------
1. Run TotalRecalls.exe (no admin rights needed).
2. Pick a provider and follow the on-screen login steps (an embedded sign-in
   window opens — you log in normally, and the app reads the session; it
   never sees your password).
3. Choose conversations and click Download. Your files land in
   TotalRecalls-download\ (or the folder you choose).

SUPPORTED PLATFORM
------------------
Windows 10 / 11, 64-bit. (macOS/Linux are on the roadmap.)

NOTES
-----
- TotalRecalls runs locally. Your chat data never leaves your machine
  except in the provider's own normal browser session.
- If something breaks, email support@totalrecalls.app — a human reads
  every message.
