# TotalRecalls — Own Every AI Conversation  
Modern Astro + React + Tailwind redesign

TotalRecalls is a small Windows app that saves your ChatGPT, Claude, Perplexity, Gemini, and Grok conversations into a private folder on your computer — readable Markdown + JSON you keep forever.

This repository contains the **complete marketing website redesign**, implemented using:

- **Astro** (UI framework)
- **React islands** (component architecture)
- **TailwindCSS** (styling)
- **Vitest + React Testing Library** (unit tests)
- **GitHub Actions CI** (build + test + coverage)
- **100% coverage enforcement**

- Section padding: `py-20`
- Typography scale:
  - `text-4xl` hero headline
  - `text-3xl` section titles
  - `text-2xl` subsection titles
  - `text-xl` card titles
- Color palette:
  - `bg-white`, `bg-gray-50`, `bg-gray-100`
  - `text-gray-700`, `text-gray-600`
- CTA:
  - Primary: `bg-black text-white`
