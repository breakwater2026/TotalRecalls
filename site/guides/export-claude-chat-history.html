Why Claude history is easy to lose

  • UI changes and workspace switches break muscle memory
  • Copy-paste doesn’t scale past a few conversations

What TotalRecalls does for Claude

On Windows, TotalRecalls can connect using your local Claude session and export conversations into a provider folder with Markdown + JSON per chat.

  1. Install TotalRecalls
  2. Select Claude
  3. Complete local sign-in when prompted

Good practices

  • Export after major writing projects, not only when you feel panic
  • Name your disk folder clearly, e.g. AI-Archive/Claude
  • If you use multiple AI tools, keep sibling folders per provider
