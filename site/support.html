Help & install

For people who just want the app to work — no technical background needed.

Download

Use the official button on the home page (or below). Save the zip file, open it, then double-click TotalRecalls.exe.

Download for Windows

Windows “protected your PC”

Windows shows this for new apps that are not yet code-signed.

  • Click More info
  • Click Run anyway

Only do this if you got the file from totalrecalls.app (or our official download link).

Smart App Control / company PCs

Some Windows setups block all unsigned apps with no override. On those machines the app cannot run until we ship a signed installer. A home Windows 10/11 PC usually allows “Run anyway”.

Using the app

  1. Open TotalRecalls
  2. Choose an AI service from the list
  3. Click Log in (or for Gemini, choose your Google Takeout folder)
  4. Pick a folder for your export
  5. Start export and wait for the progress to finish

Where did my files go?

Wherever you chose in the app. Many people use a folder like TotalRecalls-export in their user folder. Inside you’ll see a Library folder with one subfolder per AI service.
